Set up two-step verification

Your setup code was right. Set up two-step verification now, to continue.

  1. Install an authenticator app on your phone if you don't have one, such as Google Authenticator, Microsoft Authenticator or 1Password.
  2. Add NWR Stream Manager to it: scan this QR code, open this setup link on the phone, or enter the key below in the app.
  3. Check it's in the app as NWR Stream Manager, . If you enter the key yourself, give it that name. Each computer you use NWR Stream Manager on has its own entry, so the name says which one it's for.
  4. Enter the 6-digit code the app then shows.
